# Quote Desk

Independent demo built by Vinil Polepalli (vinilpolepalli.com), inspired by the problem space GUILD (YC S26) works in. Not affiliated with or endorsed by GUILD.

Machine-shop quoting and capacity desk for generic precision-machined parts. Every number is invented sample data; flags are plain deterministic arithmetic with fixed thresholds shown below each quote. No real customers, no live data, no defense claims.

Static export of a Next.js app. Built with Claude Code.
